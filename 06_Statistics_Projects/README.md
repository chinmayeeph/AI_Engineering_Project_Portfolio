# 📊 Statistics Projects

A collection of hands-on projects focused on understanding data, applying statistical methods, testing hypotheses, interpreting uncertainty, and making data-driven decisions.

This folder documents my journey from foundational statistics to practical statistical analysis for Data Analytics, Data Science, Machine Learning, and AI Engineering.

> **Current status:** Project ideas and learning roadmap. Each project will be marked as completed as it is implemented, validated, and documented.

---

## 🎯 Objectives

- Understand descriptive and inferential statistics.
- Summarize and interpret real-world datasets.
- Learn probability distributions and random variables.
- Understand sampling, estimation, and confidence intervals.
- Formulate and test statistical hypotheses.
- Interpret correlation and investigate relationships between variables.
- Understand regression, uncertainty, and statistical assumptions.
- Analyze experiments and A/B tests.
- Communicate findings using clear visualizations and plain language.
- Build the statistical foundation required for Machine Learning.

### 2. Probability Fundamentals
- Random experiments and events

### 3. Probability Distributions

### 7. Experimental Design

### 8. Bayesian Statistics and Simulation
- Prior and posterior distributions
- Likelihood

- Monte Carlo simulation
- Random sampling
- Modeling uncertainty

## 🗂️ Recommended Project Structure

Each substantial project should have its own folder.

```text
06_Statistics_Projects/
│
├── README.md
│
├── 01_descriptive_statistics_explorer/
│   ├── README.md
│   ├── data/
│   ├── notebooks/
│   ├── src/
│   ├── tests/
│   └── outputs/
│
├── 02_probability_simulator/
│   ├── README.md
│   ├── notebooks/
│   ├── src/
│   ├── tests/
│   └── outputs/
│
├── 03_distribution_visualization/
│   ├── README.md
│   ├── notebooks/
│   ├── src/
│   └── outputs/
│
└── ...
```

**Folder guidelines:**

- `data/` — datasets or instructions for obtaining them.
- `notebooks/` — experiments, explanations, and visualizations.
- `src/` — reusable Python functions.
- `tests/` — tests for calculations and edge cases.
- `outputs/` — generated charts, tables, and reports.
- `README.md` — research question, methodology, assumptions, findings, and limitations.

For a beginner project, one Jupyter notebook and a README are enough. Add a `src/` package and tests when the project becomes more complex.

## 🗺️ Recommended Learning Order

1. **Descriptive Statistics Explorer** — understand how to summarize a dataset.
2. **Student Marks Distribution Analysis** — learn percentiles, spread, and distributions.
3. **Probability Simulator** — develop probability intuition through experiments.
4. **Distribution Visualization Toolkit** — explore common probability distributions.
5. **Sampling and Sampling Bias Study** — understand why representative data matters.
6. **Confidence Interval Calculator** — learn how estimates express uncertainty.
7. **Hypothesis Testing Toolkit** — understand statistical evidence.
8. **A/B Testing Analysis Toolkit** — apply statistics to practical product decisions.
9. **Linear Regression Diagnostics** — connect statistics with Machine Learning.
10. **End-to-End Statistical Investigation** — combine analysis, validation, and communication.

**Recommendation:** Begin with small datasets and simulations. Focus on what a statistical measure means, when it is appropriate, and how to interpret it—not just how to calculate it.

## 💡 Guiding Principle

**Ask a question → Understand the data → Choose a statistical method → Check assumptions → Interpret uncertainty → Communicate the conclusion.**

The goal is not simply to calculate statistics. It is to learn how to reason carefully with data, evaluate evidence, and make decisions without overstating what the results prove.
