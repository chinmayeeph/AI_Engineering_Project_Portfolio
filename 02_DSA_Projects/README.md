## 📊 Implementation Documentation Standard

For each algorithm or data structure, document:

1. **Problem statement:** What problem does it solve?
2. **Approach:** How does the solution work?
3. **Implementation:** Include readable Python code.
4. **Example:** Demonstrate input and output.
5. **Complexity:** Explain time and space complexity.
6. **Edge cases:** Test empty inputs, duplicates, boundary values, and invalid inputs where relevant.
7. **Testing:** Include automated tests when appropriate.
8. **Comparison:** Compare alternative approaches when useful.

## ✅ Completion Checklist

- [ ] Understand the problem before coding.

## 🚀 Learning Roadmap

1. Begin with arrays, strings, searching, and sorting.
2. Practice stacks, queues, linked lists, and hash maps.
3. Learn recursion, trees, heaps, and graph traversal.
4. Practice common patterns such as two pointers and sliding windows.
5. Study greedy algorithms and dynamic programming.
6. Benchmark selected implementations and investigate performance trade-offs.
7. Apply these skills to technical interview problems and larger Python projects.
