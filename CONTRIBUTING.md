# Contributing Guidelines

Thank you for your interest in improving this AI Engineering Project Portfolio!

## 1. How to Contribute

You can contribute by:

- Reporting bugs or documentation errors.
- Suggesting project improvements.
- Improving code readability and maintainability.
- Adding useful tests or examples.
- Suggesting improvements to setup instructions.

## 2. Before Making a Contribution

- Check existing issues to avoid duplicate discussions.
- For substantial changes, open an issue to discuss your proposed approach first.
- Keep changes focused and explain why they are useful.

## 3. Code Quality

- Write readable, maintainable code.
- Use meaningful variable and function names.
- Document setup and execution steps.
- Add tests for important functionality where appropriate.
- Handle invalid inputs and expected failure cases.

## 4. Data, Security, and Licensing

- Never commit API keys, passwords, access tokens, or private credentials.
- Do not upload confidential, personal, or restricted datasets.
- Check dataset, model, and third-party asset licenses.
- Attribute external resources where required.
- Document important limitations and assumptions.

## 5. Reporting Issues

When reporting an issue, include:

- The affected project.
- A description of the problem.
- Steps to reproduce the issue, if applicable.
- Expected and actual behavior.
- Relevant error messages without exposing secrets.

## 6. Pull Requests

- Keep pull requests focused on a specific improvement.
- Explain what changed and why.
- Include tests or screenshots when useful.
- Update relevant documentation.

Thank you for helping make this portfolio better!
