# Security Policy

## Reporting a Security Issue

If you discover a security issue in this repository, please avoid publishing sensitive exploit details or credentials in a public issue.

For a private report, use GitHub's available private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner privately through an appropriate channel.

## Responsible Disclosure

Please include:

- The affected project or file.
- A description of the potential issue.
- Steps to reproduce it safely.
- Any relevant impact or suggested mitigation.

## Security Practices

Projects in this repository aim to:

- Keep secrets out of source control.
- Validate untrusted input.
- Use appropriate dependency versions.
- Document known security limitations.
- Avoid exposing private data in examples, logs, or test fixtures.

This is a learning and portfolio repository. Individual projects may have different security guarantees, and no production-security claim should be assumed without verification.
