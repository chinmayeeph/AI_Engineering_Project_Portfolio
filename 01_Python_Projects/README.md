## ✅ Project Completion Checklist

A project is considered complete when it has:

- [ ] A clear problem statement and project objective
- [ ] Working Python implementation
- [ ] Meaningful input validation and error handling
- [ ] Tests for normal cases and edge cases, where appropriate
- [ ] A project-specific README with setup and usage instructions
- [ ] Dependencies documented when external packages are used
- [ ] Example usage or screenshots, when useful
- [ ] No API keys, passwords, or private data committed
- [ ] A successful run and documented limitations
